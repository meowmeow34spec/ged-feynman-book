## ✨ 주요 특징 및 학습 도구

### 1. 진짜 양장본 책을 펼친 듯한 서재 경험
- **양면 펼침북 모드 & 연속 독서 목록 모드**: 데스크톱에서는 책등(제본선과 실밥)이 살아있는 좌·우 양면 펼침북으로 한 단어씩 깊이 읽고, 원할 때는 연속 목록으로 쭉 훑어볼 수 있습니다. 모바일·태블릿에서는 단면 노트로 자연스럽게 전환됩니다.
- **3가지 종이 & 스탠드 조명 테마** (`localStorage` 자동 저장):
  - **한지 주간 (Warm Hanji Cream)** — 따뜻한 미색 한지 질감과 송연묵 잉크, 인주빛 포인트
  - **고서재 세피아 (Vintage Sepia)** — 눈의 피로를 덜어주는 차분한 고서 양피지 톤
  - **심야 스탠드 (Midnight Study Lamp)** — 밤에 혼자 공부할 때 눈부심 없는 따뜻한 앰버 다크 조명
- **책 옆면 견출지 색인 탭 & 빨간 비단 책갈피 끈**: 어느 장이든 책장을 넘기듯 즉시 이동하고, 마지막으로 읽던 단어 위치를 기억해 언제든 이어서 펼칠 수 있습니다.
- **깔끔한 종이 인쇄(`@media print`) 지원**: 브라우저 인쇄(`Ctrl+P`) 시 UI 도구 모음과 가림막을 자동으로 걷어내고 종이 학습지 형태로 정갈하게 출력됩니다.

### 2. 파인만 학습법에 최적화된 개인 복습 장치
- **파인만 종이 가림막 모드 (`Space`)**: 오른쪽 해설 페이지 전체에 반투명 한지 가림막을 덮어, 왼쪽의 단어와 한자 조각만 보고 먼저 혼잣말로 설명해 본 뒤 스르륵 걷어내며 확인합니다.
- **3단계 이해도 전각 인주 도장**: `🌱 처음 봄` → `🌿 익숙해짐` → `💮 설명 가능(파인만 통달)` 단계를 기록하며, 통달 선택 시 붉은 전각 인장(`通達 · 참잘했어요`)이 종이 위에 찍힙니다.
- **여백 손글씨 메모장 & JSON 백업**: 각 단어 페이지 하단 줄노트 여백에 나만의 암기 연상법을 적어두면 자동 저장되며, **내 서재** 탭에서 모아 보거나 `.json` 백업 파일로 내려받아 소장·복원할 수 있습니다.
- **초성 · 단어 · 한자 · 뜻 실시간 통합 검색 (`/`)**: `ㄱㄴ`(`귀납`), `ㄱㅎㅂㅇ`(`기회비용`), `觀`, `돌아갈 귀` 등 어떻게 검색해도 본문 표제어·뿌리 한자·쌍둥이 개념을 즉시 찾아 연결합니다.
- **한자 조각 클릭 돋보기**: 본문의 한자 해부 타일이나 연관 개념 칩을 누르면 같은 한자를 공유하는 모든 수록 어휘와 뿌리 한자 도감 해설이 연결됩니다.

## ⌨️ 키보드 단축키

| 단축키 | 동작 |
| :---: | :--- |
| `←` / `→` | 이전 단어 / 다음 단어 책장 넘기기 (양면 펼침북 모드) |
| `Space` | 오른쪽 파인만 종이 가림막 걷기 · 다시 덮기 |
| `/` | 어디서든 통합 검색창으로 즉시 포커스 |
| `B` | 현재 펼친 단어에 빨간 책갈피 꽂기 · 빼기 |
| `1` · `2` · `3` | 이해도 도장 찍기 (`1`: 처음 봄, `2`: 익숙해짐, `3`: 파인만 통달 💮) |
| `?` / `Esc` | 단축키 도움말 열기 / 열려 있는 돋보기·모달 닫기 |

## 🗂️ 프로젝트 구조 및 실행 방법

웹에서 바로 **[라이브 서재](https://meowmeow34spec.github.io/ged-feynman-book/)** 를 열어 학습하거나, 저장소를 내려받아 별도의 서버·빌드 도구 없이 **`index.html` 파일을 브라우저에서 바로 열어도(`file://`)** 100% 동일하게 동작합니다.

```text
ged-feynman-book/
├── index.html                    # 메인 양장본 서재 마크업
├── .nojekyll                     # GitHub Pages 정적 배포 설정
├── css/
│   ├── book-theme.css            # 3종 종이·조명 테마, 양장 제본·책등·색인 탭·인쇄 스타일
│   └── components.css            # 파인만 카드, 한지 가림막, 전각 인장, 부록 UI 컴포넌트
├── data/
│   ├── ch1-korean-reading.js     # 제1장 국어 발문 · 비문학 독해 어휘 (24개)
│   ├── ch2-korean-lit-idioms.js  # 제2장 문학 개념어 · 검정고시 사자성어 (24개)
│   ├── ch3-social-history.js     # 제3장 사회 · 경제 · 정치 · 도덕 개념어 (23개)
│   ├── ch4-history-science.js    # 제4장 한국사 · 과학 핵심 개념어 (23개)
│   ├── hanja-roots.js            # 부록 A 뿌리 한자 레고 도감 (50자 · 파생 200어)
│   └── confusables-and-drills.js # 부록 B 쌍둥이 대결(20쌍) & 부록 C 실전 해독(25문항)
└── js/
    └── app.js                    # 서재 렌더링, 초성 검색, 가림막·도장·메모·백업 로직
```
